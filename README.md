# Malevolent Mail (伏魔御廚子) 👹
> **Destructive Domain: Temporary Disposable Email Engine** themed with Ryomen Sukuna cursed energy aesthetics.

A fast, privacy-focused temporary email client for Android that supports multiple free upstream mail infrastructure servers, automated OTP / 2FA extraction with clipboard injection, actionable deep link isolation, and persistent local inbox vaulting with Room.

---

### 🔥 Key Features

- **Multi-Server Node Clusters**:
  - `Mail.tm Core Server`: High-stability direct Hydra REST cluster.
  - `Mail.gw Nexus Proxy`: Fast-delivery open-source mirror node.
  - `1SecMail Gateway`: Stateless zero-auth rapid ephemeral server.
- **Sukuna Malevolent Aesthetic**:
  - Deep obsidian dark theme with glowing cursed crimson (`#FF1E44`) and cursed gold (`#FFC107`) highlights.
  - Live heartbeat pulse monitor (`🟢 [MONITORING]` / `🔴 [STANDBY]`).
  - Malevolent Shrine hero art and custom adaptive cursed flame launcher icon.
- **Smart OTP / 2FA Extractor**:
  - Automatically isolates 4–8 digit verification codes from incoming email packets.
  - Optional auto-copy to Android clipboard memory.
  - Haptic vibration pulse feedback when new security keys arrive.
- **Actionable Link Isolator**:
  - Discovers deep verification and confirmation URLs with 1-tap "Open in Browser" and "Copy URL" buttons.
- **Cursed Alias Generator**:
  - Generates aliases with custom prefixes or themed Sukuna presets (`sukuna_xxxx`, `malevolent_xxxx`, `cleave_xxxx`, `ryomen_xxxx`).
- **QR Code Identity**:
  - 1-tap high-contrast visual matrix display to quickly scan or transmit your temp address to another device.
- **Persistent Inbox Vault (Room Database)**:
  - Preserves created temporary mailboxes so you can switch between past vessels without losing active tokens.
  - Star and bookmark critical emails locally so you never lose them even after the remote mailbox expires.
